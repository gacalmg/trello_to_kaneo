Trello to Kaneo Converter

Converta um quadro exportado do Trello em um JSON pronto para o importador de projeto do Kaneo. Todo o processamento acontece no seu navegador.

Envie o JSON exportado do Trello Arraste o arquivo aqui ou clique para selecionar.

Configuração da conversão

Usada quando nenhum label do Trello indicar uma prioridade reconhecível.

Preencha apenas se o seu importador Kaneo aceitar esse identificador para o responsável.

Colunas de destino no Kaneo

Digite os nomes visíveis das colunas do seu projeto no Kaneo. O conversor calcula automaticamente o código interno usado pelo importador.

Como o código é obtido: o Kaneo cria o código interno a partir do nome da coluna. Ex.: Revisão Técnica → revisão-técnica. Exceção: se a coluna foi renomeada depois de criada, o Kaneo mantém o código antigo. Nesse caso, marque código manual. Para descobrir o código exato, exporte uma tarefa dessa coluna no Kaneo e confira o campo status.

Mapeamento das listas

Para cada lista do Trello, escolha uma das colunas que você cadastrou acima ou selecione Ignorar esta lista. O conversor nunca envia uma lista ignorada para planned.

Proteção contra Backlog: planned e archived não podem ser usados como colunas de destino. Uma lista pode ser mapeada para uma coluna real do quadro ou ser ignorada.
